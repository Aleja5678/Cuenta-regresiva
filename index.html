Publicar en GitHub Pages Gratis

Sigue estos sencillos pasos para tener tu web online

  1. 1
    Crea una cuenta en GitHub: Entra a github.com y regístrate gratis si aún no tienes cuenta.
  2. 2
    Crea un nuevo repositorio: Haz clic en el botón + (arriba a la derecha) -> New repository. Nómbralo como quieras (ej. mi-link-24nov) y asegúrate de marcarlo como Public.
  3. 3
    Sube este archivo: Dentro de tu nuevo repositorio, haz clic en Uploading an existing file. Guarda este código en tu PC como index.html y arrástralo allí. Haz clic en Commit changes.
  4. 4
    Activa GitHub Pages: Ve a la pestaña Settings de tu repositorio -> en el menú izquierdo haz clic en Pages -> En Branch selecciona main (o master) y guarda (Save).
  5. 5
    ¡Listo! En 1 o 2 minutos verás un enlace verde con tu página web publicada lista para compartir.
